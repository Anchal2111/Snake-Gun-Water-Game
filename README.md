
# Snake Water Gun Game 🐍💧🔫

A simple command-line Snake Water Gun game built using Python.

## Features

* Random computer choice
* User input handling
* Win/Lose/Tie detection
* Uses Python dictionaries and conditional statements

## How to Play

* `s` → Snake
* `w` → Water
* `g` → Gun

Enter your choice and compete against the computer!

## Technologies Used

* Python
* Random Module
